Defender PC Guard v2.0.0

Windows Defender updater + companion watchdog — with light & dark themes.

Defender PC Guard merges the Windows Defender Updater and PC Guard into one app. Use one place to update and check Defender, and to watch persistence, tamper and outbound activity. It never modifies your system beyond what you ask it to.

Theme toggle. Click Theme: Dark / Theme: Light in the footer (next to About) to switch the entire UI between light and dark at any time.

Defender Update (new tab, left of the Dashboard)

  • Update Defender — updates your virus definitions (Automatic / Online / Offline) and, optionally, the scanning engine.
  • Check Current Version — shows what's installed and compares it against the latest Microsoft has published online, so “up to date” has a clear meaning.
  • A colour-coded live log plus a plain-English summary pop-up.
  • The same Update Defender and Check Version actions are also in the footer, right where the version number is shown, so you can reach them from any tab.

The watchdog: the three things it watches

  • Persistence — what auto-starts. Snapshots Run/RunOnce keys, Startup folders, Services and Scheduled Tasks. After a baseline, any new / changed / removed entry is flagged.
  • Tamper — changes to your defences. Monitors the hosts file (hash), your DNS servers, and Defender's own settings — alerting if an exclusion is added or real-time protection is turned off.
  • Outbound — who's phoning home. Lists connections per process and flags any new process → remote-address pair, plus not-answering and burst behaviour.

It is a watchdog that alerts you, not a blocker.

The tabs

TabWhat it shows
Defender UpdateUpdate and check Microsoft Defender (definitions + optional engine), with its own live log.
DashboardLive Defender status — real-time protection, signatures, cloud, and how many exclusions exist.
Network (outbound)Live connections plus any seen in the last 5 minutes. Open, Connecting, Blocked? or Closed.
Startup / persistenceEverything that auto-starts (Run keys, Startup folder, Scheduled Tasks). Fills in automatically; Scan now refreshes it.
AlertsEvery alert, newest at the bottom. Right-click to ignore.
LogTimestamped history for this run, with the previous run's lines loaded at startup. Also written to %LOCALAPPDATA%\PCGuard\pcguard-YYYY-MM-DD.log.

Connection states explained

Shown asMeans
Open (ESTABLISHED)The connection is open and working — normal, healthy traffic.
Connecting (SYN_SENT)Handshake in progress; usually flips to Open in a moment.
Blocked?A connection stuck at SYN_SENT for 10s+ — destination not replying (down, or firewalled).
ClosedSeen recently but has since ended — normal for brief pings, update checks and API calls.

Tray, sound & behaviour

  • Minimise or close the window and it keeps running in the notification area. Right-click the tray icon for options.
  • Two distinct alert tones for outbound vs tamper/persistence, toggleable with Sound: ON/OFF.
  • Start with Windows, outbound burst detection, not-answering detection, ignore an alert, export log (TXT/CSV), and a baseline age reminder.

Run it

  • From source: python DefenderPCGuard.pyw (or Run Defender PC Guard.bat).
  • Build an exe: pip install pyinstaller then pyinstaller DefenderPCGuard.spec → dist\DefenderPCGuard.exe.

Requirements (to run from source)

  • Python 3.9 or newer — get it from python.org. In the Windows installer, tick "Add python.exe to PATH" so python works in a terminal.
  • tkinter — bundled with the standard Windows Python installer (the "tcl/tk" part), so no extra step.
  • pystray and Pillow — optional, only for the tray / minimise-to-tray icon. The app runs fine without them; it just won't minimise to the notification area.

Install the optional extras:

pip install -r requirements.txt

or directly: pip install pystray Pillow

Important

  • Keep Microsoft Defender switched on — this app complements it, not replaces it.
  • The engine update needs Administrator rights.
  • The watchdog is detection/alerting, not a blocker.
  • Data lives in %LOCALAPPDATA%\PCGuard; on-screen alerts reset each run, log files persist.
